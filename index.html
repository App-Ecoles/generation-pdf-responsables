Listes de classe en PDF

Un PDF par classe, généré à partir de l'extraction CSV de la base élèves.

Confidentialité

Le fichier est lu et transformé uniquement dans ce navigateur. Aucune donnée n'est envoyée, enregistrée ou conservée : fermer l'onglet efface tout. Les PDF sont téléchargés sur cet ordinateur.

1. Consigne d'extraction

Dans la base élèves, réaliser une extraction personnalisée. Dans le périmètre, ajouter le critère Niveau de responsabilité avec la valeur Représentant légal, en plus du critère année en cours. Ensuite, sélectionner les données suivantes, dans cet ordre :
